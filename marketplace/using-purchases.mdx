Once you have a model or skill from the Marketplace, it is in your Library. To use it, add it to a deal or chat.

## Starting from the Item's Page

When you own an item, its Marketplace page has two ways to start:

| Button                                      | What it does                                                                         |
| ------------------------------------------- | ------------------------------------------------------------------------------------ |
| **Tailor Your Model** or **Try This Skill** | Opens a new chat with the item already in it                                         |
| **Use in Deal**                             | Lets you pick a deal, or create a new one, then imports the item and opens a chat there |

Either way, Apers starts working as soon as the chat opens. With a model, it begins tailoring the model to your deal. With a skill, it shows you what the skill can do or asks for what it needs. Like any chat, this uses Smart Request Credits.

## Starting from the Library or a Deal

- In your **Library**, click **Use in deal** on the item and choose a deal.
- In a deal or chat, click **Import from Library** in the Data Room and select the item. See [Using Files](/library/03-using-files).

The deal gets its own copy of the item. Changes you make there don't change the copy in your Library.

## Using Models

A model is a spreadsheet. Once it's in a deal's Data Room, ask Apers to fill in your deal's numbers, run scenarios, or adapt it, just as you would with any other model. See [Working with Existing Models](/ai-excel-modeling/working-with-existing-models).

Many Marketplace models come with a skill that explains how the model is laid out and how to use it. Apers reads it when it works with the model. To read it yourself, open the triple-dot menu (⋮) on the file and choose **View Skill**.

<Tip>
  To reuse a version you've tailored, save it from the deal to your Library with **Save to Library**.
</Tip>

## Using Skills

There is nothing to switch on. A skill is in use once it's in a deal:

<Steps>
  <Step title="Add the skill to a deal">
    Use any of the ways above. In the deal's Data Room, the skill is listed under **Skills Loaded**.
  </Step>
  <Step title="Chat normally">
    When your request matches what the skill is for, Apers reads the skill and follows it. You don't select it.
  </Step>
</Steps>

<Note>
  A skill in your Library, under **Available Skills**, isn't used in a deal until you add it to that deal. Add it to each deal where you want it. See [Skills](/documents/organizing-the-data-room#skills).
</Note>

## Getting the Latest Version

Marketplace items are updated over time. When a newer version of an item you own is available, its Marketplace page shows **Update to latest version**. Click it to replace the copy in your Library with the current version. If you've edited that Library copy, your edits are replaced too.

If you haven't changed your Library copy, Apers also brings it up to date when you add it to a deal.

<Tip>
  To find an item's Marketplace page from your Library, click **Marketplace** on the item's row.
</Tip>

## Sharing with a Colleague

Each user has their own Library, so an item you get isn't automatically available to your team. There are two ways to share it:

- **Work in the same deal.** Once the item is in a deal's Data Room, everyone on that deal can use it there.
- **Send a copy.** Open the file and click the share icon (**Share with a user**), then enter your colleague's email. Apers copies the file into their Library and notifies them. They need an Apers account.

## Quick Reference

| Action                           | Where                                                    |
| -------------------------------- | -------------------------------------------------------- |
| Find your items                  | Library, or items marked **Owned** in the Marketplace    |
| Add an item to a deal            | **Use in Deal** on the item's page, **Use in deal** in the Library, or **Import from Library** in the Data Room |
| Use a skill                      | Add it to the deal; Apers uses it when it's relevant     |
| Get the latest version           | **Update to latest version** on the item's page          |
| Share with a colleague           | **Share with a user** on the file                        |

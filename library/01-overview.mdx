The Library is your personal knowledge management system. Store files here and reuse them across all your future deals.

## What You Can Store

- Market assumptions
- Financial models
- Word document templates
- Any other reusable files

## Accessing the Library

Click the **Library** tab on the left side panel to open your Library.

## Key Features

|                          | Description                                                  |
| ------------------------ | ------------------------------------------------------------ |
| **Upload files**         | Drag and drop files directly into the Library                |
| **Save from Chats**      | Push files from any Chat or Deal into the Library            |
| **Import to Deals**      | Pull files from the Library into any Chat or Deal            |
| **Share files**          | Copy a file into a colleague's Library                       |

<Info>
  The Library creates a feedback loop. As you build models and templates, save them so you can reuse them later.
</Info>

<Note>
  Each user has their own Library. To give a colleague a file, open it and click the share icon (**Share with a user**). Apers copies the file into their Library and notifies them. They need an Apers account.
</Note>
